## 1. 视觉与设计

### 1.1 真实视觉素材替换占位符（★★）

- 指挥家头像目前是字母占位，替换为真实照片（可用 Unsplash / Pexels 免费版权素材），加载时做模糊渐显（`blur-up`）
- 为"常演曲目"增加作曲家肖像小图或乐谱手稿底图
- Hero 区背景可加一张虚化的音乐厅照片 + 暗色蒙层，替代纯粒子

### 1.2 主题与氛围（★★）

- **音乐厅灯光模式**：根据"演出进行中"或时间切换灯光色调（暖金 / 冷蓝）
- **指挥家模式切换**：深色"舞台"主题 ↔ 浅色"排练厅"主题，加一键切换按钮
- 配色抽成 CSS 变量统一管理（目前色值散落在各选择器中），方便换肤

### 1.3 排版与细节（★）

- 大标题使用更讲究的中西文混排（Playfair Display 配思源宋体的字距、字号微调）
- 各 section 增加装饰性分隔符（如 `~ ~ ~` 或乐谱小节线 `|:`）
- 按钮 hover 加金属质感微动效（高光扫过）

## 2. 音频体验

### 2.1 更真实的声部音色（★★★）

- 当前试听是双振荡器合成，音色偏"电子"。升级方向：
  - **SoundFont（SF2）本地采样**：加载各声部乐器的采样波形，通过 `BufferSource` 播放，音色接近真实
  - 或预录各声部 3-5 秒示范音频（MP3/Ogg），保留点击触发逻辑
- 加入**颤音（vibrato）与和弦**：弦乐用和弦而非单音，打击乐用噪声包络模拟鼓槌敲击

### 2.2 全局音频控制（★★）

- 添加**播放/暂停 + 音量滑块**的悬浮音频控制台
- 用 Web Audio 的 `AnalyserNode` 做**频谱可视化**（金色波形随声音跳动），与画布粒子联动

### 2.3 迷你播放器（★★★）

- "常演曲目"区块增加**曲目试听列表**：选中后循环播放对应片段，当前曲目高亮 + 进度条
- 可结合 2.1 的采样方案，让六首"常演曲目"都能试听

## 3. 内容与功能

### 3.1 数据与状态（★）

- 演出日程目前是硬编码数组，改为**外部 `data/concerts.json`** + `fetch` 加载，内容更新无需改 JS
- 演出卡片增加**选座 / 加日历（.ics 下载）**按钮

### 3.2 购票流程完善（★★）

- 表单扩展：选择演出场次、票档（VIP / 金卡 / 普通对应价位）、购票数量
- 提交后生成**订单摘要卡片**（场次 + 票档 + 金额），再确认
- 加**座位图**（Canvas 或 SVG 半圆看台，可点击选座，已售座位置灰）——这是最出彩的功能之一

### 3.3 新增内容区块（★★）

- **乐团历史时间线**：横向滚动时间轴（1896 创立 → 里程碑事件）
- **后台花絮 / 排练室**：图片轮播 + 短视频
- **乐友社区**：文字留言墙（可先本地 localStorage 实现，后续接后端）
- **订阅页**：邮件订阅演出提醒（表单已有基础，加成功态展示）

## 4. 交互与动效

### 4.1 滚动叙事（★★）

- 用 CSS `scroll-timeline` 或 JS 实现**章节随滚动推进的"乐章"进度条**（顶部细条，标注"第一乐章…终章"）
- 各 section 入场动画目前较单一，可加**交错入场**（子元素按序延迟浮现）

### 4.2 声部卡片动效（★★）

- 试听时卡片**共振动画**（轻微缩放 + 边框光晕随音量律动，配合 2.2 的 AnalyserNode）
- 卡片翻转（正面文字 / 背面乐器插图）

### 4.3 手势与彩蛋（★）

- 指挥家区块加**手势感应**：鼠标画圈时粒子跟随轨迹（"你也是指挥"）
- 敲三下标题触发**开场锣声**（Web Audio 合成）

## 5. 工程化与性能

### 5.1 构建工具（★★）

- 引入 **Vite** 做本地开发（HMR）与打包，代码模块化拆分：
  ```
  src/
    main.js        入口
    modules/canvas.js    粒子背景
    modules/audio.js     Web Audio 合成
    modules/events.js    演出渲染
    modules/form.js      表单校验
    data/concerts.json
  ```
- 加 `package.json` 与 Lighthouse CI 预算

### 5.2 性能（★）

- 画布粒子在 `prefers-reduced-motion` 或低端设备**自动降级**（减少数量 / 停用）
- 图片加 `loading="lazy"`，字体用 `font-display: swap`（Google Fonts 已支持）
- 目标 Lighthouse 性能分 ≥ 90

### 5.3 测试与质量（★★）

- 关键交互加单元测试（Vitest + happy-dom）：表单校验、演出渲染、数字滚动
- CI（GitHub Actions）：lint（ESLint + stylelint）+ 测试 + 构建

## 6. 可访问性与 SEO

### 6.1 可访问性（★）

- 声部卡片已有 `tabindex="0"`，补充**键盘 Enter/Space 触发试听**（目前只绑定了 click）
- 试听按钮加 `aria-label`，表单错误提示用 `aria-live="polite"` 播报
- 对比度检查：金色文字在深色背景上部分位置对比度偏低（目标 WCAG AA ≥ 4.5:1）

### 6.2 SEO 与元数据（★）

- 补全 Open Graph / Twitter Card（分享卡片：乐团名 + 图 + 描述）
- 加 JSON-LD 结构化数据（`Event` 列表 + `Organization`）
- 补 `robots.txt`、`sitemap.xml`

## 7. 多端与部署

### 7.1 国际化（★★）

- 文案抽成 `i18n` 字典（zh-CN / en），导航加语言切换
- 曲目区块同步展示作曲家英文名（如 "Mahler · 马勒"）

### 7.2 PWA 化（★★）

- 加 `manifest.json` + Service Worker：可安装到桌面、离线可打开
- 演出日程离线可用（数据已本地化，成本很低）

### 7.3 部署（★）

- 已推送到 GitHub，可直接用 **GitHub Pages** 发布（设置 → Pages）
- 或 Cloudflare Pages / Vercel，加自定义域名
- 配 CNAME 与 HTTPS（Pages 默认提供）
