# AURORA 交响乐团 · 演示站点

一个以交响乐为主题的纯前端演示网站，使用原生 HTML + CSS + JavaScript 构建，无任何框架或构建工具依赖。

## 功能特性

- **背景画布** — 漂浮上升的金色音符粒子（Canvas 实现）
- **数字滚动动画** — 乐团统计数字在进入视口时递增
- **声部试听** — 四大声部卡片可点击试听，音色由 Web Audio API 现场合成（双振荡器 + 低通滤波 + 包络），无需任何音频文件
- **演出日程** — 由 JS 数据动态渲染，支持"已售罄"状态
- **购票表单** — 姓名 / 邮箱 / 会员等级校验，含成功与错误提示
- **响应式布局** — 移动端汉堡菜单，深色 + 金铜色调设计

## 页面结构

| 区块 | 锚点 | 说明 |
| --- | --- | --- |
| 导航 | `#nav` | 固定顶栏，滚动后出现阴影 |
| 首页 | `#home` | Hero 区 + 统计数字 |
| 声部 | `#sections` | 弦乐 / 木管 / 铜管 / 打击乐试听卡片 |
| 指挥家 | `#conductors` | 四位指挥介绍 |
| 常演曲目 | `#repertoire` | 六首经典曲目 |
| 演出日程 | `#concerts` | JS 动态渲染的演出列表 |
| 购票 | `#ticket` | 乐友申请表单 |

## 文件说明

```
index.html   页面结构（导航、各区块、表单）
style.css    样式（配色、布局、响应式、动画）
script.js    交互逻辑（画布、数字动画、声部试听、演出渲染、表单校验）
```

## 使用方法

无需安装依赖，直接用浏览器打开 `index.html` 即可：

```bash
open index.html
```

> 声部试听需用户点击触发（浏览器自动播放策略限制）。

## 技术栈

- HTML5 / CSS3 / 原生 ES6+ JavaScript
- Canvas API（粒子背景）
- Web Audio API（声部音色合成）

## 许可

演示项目，自由使用。
